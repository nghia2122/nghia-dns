NGHIA DNS PRO – GitHub Pages

1. Giải nén ZIP.
2. Tải index.html và NGHIA_DNS_PRO.mobileconfig lên thư mục gốc (root) của repository GitHub Pages.
3. Giữ nguyên tên file NGHIA_DNS_PRO.mobileconfig.
4. Mở website GitHub Pages bằng Safari trên iPhone để tải và cài profile.

Profile này dùng NextDNS Configuration ID 176163. Quản lý bộ lọc tại https://my.nextdns.io/.
Không chia sẻ file nếu bạn không muốn người khác sử dụng chung cấu hình/giới hạn truy vấn của bạn.
